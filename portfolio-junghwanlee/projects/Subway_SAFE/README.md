알고리즘 고찰
A* 알고리즘의 경로 비용을 어떻게 정의 할 것인가? 
g(n), 댐퍼의 개도율, h(n) 3가지를 종합적으로 고려하여 경로 비용을 책정할 예정임
g(n) : 총 손실 헤드 값으로 정의 함
총 손실 헤드 = 마찰 손실헤드(Friction Loss Head) + 관로 형태에 따른 손실(국부 손실 or Minor Loss)
댐퍼의 개도율 : 공기조화기와 각 구역에 있는 댐퍼와의 거리에 따라 조정하는 방식 고려

이유 : 공기조화기에서 먼 구역일수록 덕트 시스템에서의 마찰손실이 더 커지며, 이로 인한 풍량이 감소할 가능성이 있음
-> 더 먼 구역 일수록 더 많은 공기가 전달 될 수 있도록 댐퍼의 개도율을 적절히 조정해주는 것이 중요함
(a) 공기 조화기에서 가까운 구역 -> 개도율 낮춤(다른 구역에 더 많은 공기를 공급 할 수 있도록 함)
(b) 공기 조화기에서 먼 구역 -> 개도율 높임(충분한 공기 흐름 보장)
(c) 중간 구역 -> 개도율 중간(압력 균형 맞추기)
h(n) : 화재 발생 구역과의 거리를 비례 계산하여 반영한 값으로 정의 함
화재 발생 구역과 거리가 가까우면 h(n)에 작은 값, 거리가 멀면 큰 값을 넣어 경로 비용에 차이를 두어 최단경로(배연 최단 경로)를 찾을 수 있음
weighted A* 알고리즘을 사용하여 'w'을 추가하여 평상시와 화재시를 구별하여 적용 가능하도록 알고리즘을 설정함
w = 0(평상시), w = 1(화재시)
추가 고려해야 할 점
g(n), h(n), 거리에 따른 댐퍼 개도율을 적절히 사용하여 수식을 만들어야 하는데 정량적으로 정의하는데 어려움이 있음
-> 실제와 유사한 데이터(환경) 수치 값을 받아 적용 시켜 보아야 할 것으로 보임
